# Nexum Technical Group — concept website

Static concept site for a new Benelux technical-services group built around All-Rack and S4 Benelux.

## Files
- `index.html` — page structure and copy
- `styles.css` — visual design
- `script.js` — mobile menu, reveal animations, cursor effect

## Run locally
Open `index.html` directly, or run any static web server in this folder.

## Notes
- Nexum Technical Group is a working name. Perform trademark, company-name and domain clearance before use.
- `hello@nexumtechnicalgroup.com` is a placeholder address until the domain/email is confirmed.
- The design direction uses editorial typography, generous spacing, independent company identities and a strong group-level narrative. It is not a copy of GroundBirds.
- Company statements are based on publicly available pages from All-Rack and S4 Benelux and should be reviewed by management before publication.
